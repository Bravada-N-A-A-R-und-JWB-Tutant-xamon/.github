# 🏴 Xarmbrassadora-Bravada

> **Официальный суверенный хаб разработки и независимой дистрибуции.**

---

### 💬 О чем этот репозиторий?

Здесь пишется независимый native-софт на Qt Quick / QML / C++ под Ubuntu Touch и Lomiri. 

После того как администрация OpenStore показала свой уровень и начала раскидывать баны из-за личных обид, мы забили на их площадки и подняли свой собственный автозавод: **JWB-Denda**. Всё собирается напрямую через GitHub CI/CD и раздаётся пользователям без цензуры, бюрократии и прочей шелухи.
