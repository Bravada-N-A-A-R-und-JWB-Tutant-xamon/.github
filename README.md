## 🛡️ РУССКИЙ — Манифест Цифрового Сопротивления (Суверенный Код)

**Этот репозиторий — больше не просто архив с кодом. Это суверенная территория.**

Официальный OpenStore экосистемы Ubuntu Touch окончательно превратился в частную песочницу двух синдромных вахтёров — **Tobiyo** и **Rodney**. Эти люди, дорвавшись до минимальной власти модераторов, уничтожают труд независимых разработчиков, выкашивая аккаунты и удаляя нативные приложения (такие как игра *Hash!*, MP3 Tag Editor, SVG Editor) **БЕЗ ОБЪЯСНЕНИЯ ПРИЧИН**, без код-ревью и без права на апелляцию. 

Их пугает чистый, оптимизированный код на Qt Quick и C++, написанный без использования их раздутых, лагающих официальных Lomiri-компонентов. Официальные русскоязычные чаты UBports также захвачены ангажированными элементами и русофобами, готовыми банить за любое проявление независимого мнения.

**Мы не будем играть по их правилам. Мы объявляем цифровой партизанский децентрализованный фронт.**

### Наши принципы:
1. **Прямая дистрибуция:** Все `.click` пакеты приложений (включая логическую игру *Hash!*) теперь распространяются свободно и напрямую через вкладку **Releases** в этом GitHub-сообществе. Нам не нужна их цензура, чтобы доносить софт до реальных пользователей.
2. **Исключение для Свободных Братьев:** Наш протест направлен исключительно на центральную деспотичную администрацию. Мы выражаем глубокое уважение и полную солидарность нашим независимым каталанским друзьям из **UBports Catalunya**. Они остаются верны принципам истинного опенсорса, свободы слова и децентрализации.
3. **Сохранение идентичности:** Проекты организации развиваются под знаменем кастомного геометрического флага *Бравада* (Xarmbrassadora). Наша философия объединяет строгую геометрию оригами, чистоту логики и силу независимого славянского кода.
